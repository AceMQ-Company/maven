AceMQ Maven repository

Published artifacts for org.acemq. No credentials needed.

Maven

<repositories>
  <repository>
    <id>acemq</id>
    <url>https://acemq-company.github.io/maven/</url>
  </repository>
</repositories>

<dependency>
  <groupId>org.acemq</groupId>
  <artifactId>acemq-amqp-core</artifactId>
  <version>0.2.3</version>
</dependency>
<dependency>
  <groupId>org.acemq</groupId>
  <artifactId>acemq-transport-rabbitmq</artifactId>
  <version>0.2.3</version>
  <scope>runtime</scope>
</dependency>

Gradle

repositories {
    mavenCentral()
    maven { url = uri("https://acemq-company.github.io/maven/") }
}

dependencies {
    implementation("org.acemq:acemq-amqp-core:0.2.3")
    runtimeOnly("org.acemq:acemq-transport-rabbitmq:0.2.3")
}

Sources and Javadoc jars are published alongside every artifact. Browse the tree under org/acemq/.

Why not Maven Central

Central is permanent: nothing published there can be removed or altered. That is the wrong trade before 1.0, while coordinates and API shape are still settling. Here a bad release can be deleted.

The cost is real and worth knowing before you depend on this. Because these artifacts are not on Central, any library that depends on AceMQ obliges its consumers to add this repository too. That is fine for applications and awkward for libraries. AceMQ moves to Maven Central for 1.0.
